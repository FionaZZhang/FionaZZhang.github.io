# Travel photos

## Naming

```
<slug>-1.jpg   <slug>-2.jpg   <slug>-3.jpg
```

- Use the exact slug below (e.g. `gold-coast`, not `goldcoast`).
- Add them in order: `-1` first, then `-2`, then `-3`.
- Lowercase `.jpg` only. GitHub Pages is case-sensitive, so `.JPG` will 404.
- JPEG only. HEIC does not display in browsers.
- Long edge ~900px is plenty; the card renders them small.

Convert and resize anything new:

```sh
sips -s format jpeg -s formatOptions 72 -Z 900 IMG_1234.HEIC --out public/travel/milan-2.jpg
```
